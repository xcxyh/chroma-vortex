# 《全搅进去》

0 卡搅奶油与电子甜品 DIY 解压小游戏（小红书小工具 V1.1.3 独立版）。

## 核心玩法
- **甜品闯关（72 关）**：松手出杯、今日特调、一笔拉花、旋纹寻色，第 1–2 关带引导教学，第 3 关起盲搅测手感。
- **甜品自助吧**：自由选奶底、淋酱与 6 款实拍小料（草莓、蓝莓、威化、巧克香蕉、弹跳珍珠、奥利奥/彩糖），自由调配出杯。
- **成就手账与晒评论**：内置 WebAudio 立体声搅拌音效与原创配乐《糖勺跳跳》，支持 540×675 出杯小票导出、小红书同步直调一键晒评论、好友分享与每日排行榜。

## 本地独立运行

python3 -m http.server 8765
