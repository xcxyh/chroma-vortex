# 《全挤上去》 Cream Atelier

奶油胶手机壳 DIY 解压小游戏（小红书小工具 V1.0 独立版）。

## 核心玩法
- **苹果最新 5 款机型自由切换**：支持 `iPhone 17 Pro Max`、`iPhone 17 Pro`、`iPhone 17`、`iPhone 16 Pro Max`、`iPhone 16`，真实还原横向三摄条、竖排药丸双摄与经典方圆三摄模组，切换机型自动重算奶油避让裁剪与覆盖率。
- **纯 Canvas 2D 立体裱花引擎**：零 WebGL（兼容平板与荣耀设备），支持 **8 齿波浪嘴 / 玫瑰大花嘴 / 丝带扁花嘴** 与 8 款奶油胶（含 3 款双色拼挤），自动紧贴镜头模组裁剪。
- **3D 树脂配件与点缀**：内置 8 款高质感 3D 树脂配件 PNG（奶油小熊、亮面草莓、爱心曲奇、粉色蝴蝶结、微笑云朵、双樱桃、抹茶马卡龙、彩虹棉花糖）及白珍珠、彩色糖针、五瓣小花、星光细闪。
- **双模式 + 高清定制图保存 & DIY 材料清单**：18 关渐进式接单闯关 + 自由挤壳工坊 + 12 格个人作品集；支持一键保存 **750×1200 正面无倾斜高清手机壳定制图**（附机型、底壳和完整材料清单，方便发给定制店照做或分享，并内置长按大图保存兜底）与 **540×675 出单小票**，接入小红书一键晒评论、分享、发笔记与每日排行榜。
