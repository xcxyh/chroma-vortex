# 《全挤上去》 Cream Atelier

奶油胶手机壳 DIY 解压小游戏（小红书小工具 V1.0 独立版）。

## 核心玩法
- **纯 Canvas 2D 立体裱花引擎**：零 WebGL（兼容平板与荣耀设备），支持 **8 齿波浪嘴 / 玫瑰大花嘴 / 丝带扁花嘴** 与 8 款奶油胶（含 3 款双色拼挤），自动紧贴镜头模组裁剪。
- **3D 树脂配件与点缀**：内置 8 款高质感 3D 树脂配件 PNG（奶油小熊、亮面草莓、爱心曲奇、粉色蝴蝶结、微笑云朵、双樱桃、抹茶马卡龙、彩虹棉花糖）及白珍珠、彩色糖针、五瓣小花、星光细闪。
- **双模式 + DIY 材料清单小票**：18 关渐进式接单闯关 + 自由挤壳工坊 + 12 格个人作品集，出单生成 **540×675 手作小票** 并自动统计「本款 DIY 材料清单」，支持小红书一键晒评论、分享、发笔记与每日排行榜。

## 本地独立运行
```bash
python3 -m http.server 8765
# 打开 http://127.0.0.1:8765/?preview=1
```
