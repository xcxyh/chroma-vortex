# 全搅进去 · Chroma Vortex

用手指或鼠标搅动湿颜料的浏览器小游戏。主入口为自由搅拌，也可单独选择 12 个教学、猜色和目标调色关卡。

![铬钢调色盘里盘旋的青蓝、洋红和黄色湿颜料](assets/chroma-vortex.webp)

## 试玩

下载或克隆仓库后，可以直接用桌面浏览器打开 `index.html`，也可以运行本地服务。

```sh
git clone https://github.com/xcxyh/chroma-vortex.git
cd chroma-vortex
python3 -m http.server 8080
```

打开 [http://localhost:8080/](http://localhost:8080/)。手机连接同一局域网后，可以使用电脑的局域网地址和端口访问。项目是静态网页，Three.js 与图像素材均随仓库提供，无需安装前端依赖。

## 玩法

- 自由搅拌可以持续拖动和添色，点“重新开一盘”重置颜料。
- 所有模式都能调节画笔大小。滑杆表示笔触直径占盘径的比例，浏览器会记住上次选择。搅拌均匀度根据有颜料区域的实际色差实时估算，空盘显示“—”，单色显示 100%。
- 入门关先搅黄、蓝，再加入红色。加红后搅一笔，松手即通关，也可以点「完成本关」。
- 结算弹窗显示通关结果和得分，可直接进入下一关，或回到本盘继续搅拌。返回大厅后点「继续闯关」可接着玩。
- 猜色关可以随时搅拌，选好答案后点“揭晓答案”。猜对得 100 分并通关。猜错得 60 分，可重试本关。
- 对色关轻点颜料加入盘中，可在滴数预算内调整配比。配好后主动提交，按 CIELAB 色差评分，75 分过关。
- 成绩按得分降序排列，同分优先用时较短的记录。可查看全部或今日成绩。更改昵称会用于之后的实验。
- 通过关卡会自动收藏该轮的配方色。自由搅拌和关卡中都可点“取色收藏”，再轻点盘中具体位置，给当地的颜料色命名。取色会保留原处的纹理。
- 收藏板按稀有度排列，支持等级筛选和查看来源。同一 HEX 色号共用一张卡，已有图鉴会在读取本机存档时迁入。成绩和收藏保存在当前浏览器。

## 色卡稀有度

参考实验等概率选择 1 至 4 滴，每一滴独立、等概率地从 9 种原管颜料中选取，用游戏的 RYB 模型计算成色。以 HEX 落色，再用 CIELAB 色差 ΔE ≤ 8 统计近似配方的加权占比。常见为占比 ≥ 2%，少见为 0.5% 至小于 2%，稀有为 0.1% 至小于 0.5%，传说为小于 0.1%。色卡详情显示该色号的参考占比。

## 渲染

颜料使用 RYB 浓度、厚度及表面高度网格。新加的颜料先盖在底色上。搅动时，表层才会沿笔迹与底层混合，颜料只在笔触覆盖的相邻网格之间流动，按实际转移量混色，同时沿运笔方向压出细沟。轻划一次可以拉出清晰的色带。反复搅同一处时，笔刷会更充分地混合接触到的颜料。圆盘边缘封闭，反复贴边搅动也能保留盘内颜料。松手时保留当时的色带，关卡结算后仍可继续搅拌。Three.js r160 根据实时高度场渲染湿漆反光。缺少 WebGL 时使用同一模拟的 Canvas 2D 输出。支持触控、鼠标与笔压，震动取决于设备和浏览器支持。

## 美术素材

主视觉和关卡纹理由内置 imagegen 生成，使用 WebP 随游戏加载。主视觉文件为 `assets/chroma-vortex.webp`，四组关卡纹理为 `assets/lime.webp`、`assets/pink.webp`、`assets/blue.webp` 和 `assets/orange.webp`。

- 主视觉提示词核心为深炭色摄影棚、俯视略倾斜的铬钢调色盘、洋红与青蓝和荧光黄的厚涂丙烯漩涡、湿漆高光、飞溅颜料与金属刻槽。
- 关卡纹理提示词核心为四组微距湿颜料，依次表现黄绿斜纹、粉紫旋涡、青蓝波纹和橙红折叠，使用硬棚灯突出表面起伏。

## 作画

自由搅拌从空盘开始，点选颜料逐滴加入。取色时可以“收藏并作画”，也可以在收藏板的色卡详情选择“用这个颜色作画”。画室调色板将藏色呈现为堆起的油彩。油画笔按笔压和运笔方向铺色，颜料高度决定沟槽和反光；橡皮擦回亚麻底纹。旧草稿保留原有平涂笔迹。画室支持调整笔触、橡皮、撤销和重做。画布草稿在本机保存，可以连同画布纹理和油彩光影一起导出 1200 × 900 的 PNG。

调色板的中性油彩样本由内置 imagegen 生成，提示词核心为中灰色厚油彩、调色刀折痕、细密刷毛纹与湿亮反光，WebP 内嵌于 `assets/oil-dollop.css`，支持直接打开本地页面。显示时按藏色色号着色。
